# Pro AI Video Director (Web Version)

A professional cinematic prompt architect designed for Image-to-Video AI engines like **Seedance** and **Kling**.

## Features
- **Cinematic Shot Logic**: Generates multi-cut sequences with varied focus strategies.
- **Genre-Driven Archetypes**: Specialized camera and lighting profiles for Horror, Street Style, Interview, and more.
- **Reference Image Respect**: Focuses on cinematography and movement rather than inventing conflicting content.
- **Audio & Dialogue Distribution**: Intelligently paces audio cues across the sequence.

## How to Host on GitHub Pages
1. Create a new repository on GitHub.
2. Upload the files in this folder (`index.html`, `style.css`, `script.js`).
3. Go to **Settings** > **Pages**.
4. Select the **main** branch as the source and click **Save**.
5. Your tool will be live at `https://[your-username].github.io/[repo-name]/`.
